이중지원 체크리스트

이중지원이면 지원한 학교 모두 불합격! 내 상황이 이중지원에 해당하는지 확인하세요.

🚨
이중지원은 절대 금지! 이중지원으로 합격 시 모든 학교 합격이 취소됩니다. 담임선생님과 꼭 확인하세요!
✅ 이중지원 해당 사례 확인하기

해당하는 항목을 클릭해서 체크해보세요. 하나라도 해당되면 이중지원입니다.

✓
한 학교에 지원하여 전형에 합격한 자가 다른 학교에 지원하는 경우
✓
한 학교에 지원하여 불합격이 확정되지 않은 자가 다른 학교에 지원하는 경우
✓
타 시도 전기학교에 지원한 자가 도내(타 시도) 전기학교에 지원하는 경우
✓
전기학교 합격자가 후기학교에 지원하는 경우
✓
전기(후기)학교 전형에 합격한 자가 추가모집 또는 수시모집에 지원하는 경우
✓
고등학교에 합격 후 미등록 또는 학년 초 자퇴하고, 같은 학년도에 다른 학교 수시모집에 신입학 지원하는 경우
✓
외고·국제고·자사고 지원자가 학교장 전형 고등학교에 동시 지원하는 경우

특수교육대상자로 선정·배치된 학생이 다른 학교에 지원하는 경우

📌
학교 지원 핵심 원칙
  • 학교장전형교는 1개 학교만 선택 지원 (타 시도 포함)
  • 평준화지역 희망 시 1개 학군 선택, 학군 내 지망순서별 전체 지원
  • 졸업예정자(현 중3)는 중학교 소재지 기준으로 지원 가능 학군 결정
  • 졸업자·학력인정자는 주소지 기준으로 지원 가능 학군 결정
🔴
합격 후 주의사항
  • 1교에 합격 시 2027학년도 어떤 전형에도 지원 불가 (전국 공통)
  • 2028학년도 전형에는 지원 가능
  • 이중지원 시 모두 불합격 처리
  • 고교 졸업자는 재입학 제한 (검정고시 합격자는 가능)
✅
불합격 시 대처법
  • 전·후기 미달 학교에 추가모집, 수시모집으로 지원 가능
  • 경남은 전체 입학정원 > 졸업생 수이므로 진학 못하는 경우 없음
  • 수시모집 마감: 2027. 5. 21.(금)까지
  • 다만 선호도 높은 학교는 경쟁으로 불합격 가능
